# data/

The two annotated corpora are **not stored in this repository**. They are deposited on
FigShare, which carries the DOI, the versioning and the data licence:

- `antidepressant-weight-mentions_training-corpus_n8000.csv` — 8,000 reviews, 31 molecules
- `antidepressant-weight-mentions_evaluation-batch_n2010.csv` — 2,010 reviews, 19 molecules

DOI: 10.6084/m9.figshare.33456934
<https://doi.org/10.6084/m9.figshare.33456934>

The deposit is embargoed until the article is published.

Download both files into this directory to run the commands in the top-level README.
They are released under CC BY 4.0; the code in this repository is under Apache 2.0.
